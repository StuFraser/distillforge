# New Starter Onboarding Checklist

Use this for every new engineer. Copy it into the starter's ticket and tick items off as you go.

## Before day one (manager)

- [ ] Order laptop and confirm delivery to the starter's home address
- [ ] Create accounts: email, chat, source control, issue tracker
- [ ] Add the starter to the team calendar and the weekly planning meeting
- [ ] Choose an onboarding buddy and tell them at least a week ahead
- [ ] Send the welcome email with the day one schedule

## Day one

- [ ] Meet the team and have lunch with the buddy
- [ ] Set up the development environment using the README
- [ ] Complete the security awareness course
- [ ] Sign the confidentiality agreement and return it to HR

## First week

- [ ] Fix a starter bug (the buddy picks one labelled `good-first-issue`)
- [ ] Get the change reviewed and merged
- [ ] Shadow someone on the on-call rota
- [ ] Read the architecture overview and ask questions in the team channel
- [ ] One to one with the manager at the end of the week

## First month

- [ ] Own a small feature from design to release
- [ ] Present what you learned at the team demo
- [ ] Agree three goals with your manager for the first quarter
- [ ] Give feedback on this checklist. What was missing or confusing?

## Notes

If any step is blocked for more than a day, tell your manager. Starters should never wait for access.
